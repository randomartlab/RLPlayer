## 一、kikoflu 搜索设计拆解

### 1. 核心模型：多条件组合（非单关键词）

kikoflu 的搜索是 **条件对象集合**，不是单一输入框：

```
SearchCondition { type, value, isExclude }
  type: keyword | rjNumber | tag | circle | va
```

- 每个条件可叠加；同一类型可多值（如 2 个标签取并集）
- `isExclude` 表示**排除条件**（`$-tag:X$`），与包含条件混合构成 AND 语义
- 结果页把条件渲染成可删 chips（带「排除」样式），点 × 移除即刷新

**本质**：把「搜索语法」变成「可交互对象」，输入框只是添加条件的方式之一。

### 2. 类型专属的候选/补全

- 类型=标签/社团/声优时：**不是自由输入**，而是拉**全表建议列表**（`/api/tags`、`/api/circles`、`/api/vas`），按 count 降序，用户点选生成条件（kikoflu 用 `Autocomplete` + 全量本地过滤）
- 类型=关键词/RJ：自由输入；RJ 只输数字自动补 `RJ` 前缀
- 建议数据**内存缓存**，切类型不重复拉取

### 3. 服务器端与本地端能力对齐

- 官方服务器走组合查询语法（`$tag:..$` 等，kikoeru /api/search 全文检索引擎）
- 自建/本地后端：**App 端本地二次过滤**（拉候选作品后按条件逐项匹配），两者结果同构
- 高级筛选后置：**评分下限、年龄分级、销量区间** 作为结果集再过滤

### 4. 体验细节

- 条件 chips 横向滚动区 + 常驻输入框（添加后清空、可继续加）
- 自动保持选中条件类型；点击历史/建议即转条件
- 结果单独 Screen（search_result_screen）承载排序/分页/本地标记

## 二、本项目（RLPlayer）现状

已具备：本地/全网切换、5 类型 chips、标签/社团/CV 全表选择器（按作品数排序、输入过滤）、输入候选面板（聚合本地字段）、「组合」弹层（AND/OR + 排除 + 满足 chips）、结果含本地徽章。

**差距**：
1. 组合语义碎片化：既有「条件类型 chips 单条件模式」又有「组合模式」两套 UI，kikoflu 是一套统一的对象模型
2. 全网模式不真正支持"多值 AND 组合检索"（如 标签A + CV 同搜）——仅单条件/本地组合
3. 缺高级筛选（评分/年龄/销量区间）在搜索结果的二次过滤（本地有歌词/字幕/分级 chips，但无评分销量）
4. 建议全表未持久缓存（切页重拉）、候选与本地作品数据未联动"本地是否已有"
5. 排除语法仅本地组合弹层支持，不贯穿全 UI
6. RJ 检索在"全网"模式下不能自动补 RJ 语义（关键词里裸数字不翻译）

## 三、迭代 PRD（搜索）

### M1 统一条件对象模型（对齐 kikoflu）
- 引入 `SearchCondition{type,value,isExclude}`；本地/全网共用一套条件列表
- 输入框 + 类型 chips 只在「添加条件」时出现；已加条件渲染为 chips（可删/可排除切换）
- 保留「组合」弹层但内部也产出条件对象；删除旧「单条件搜索」分支 UI
- 排除视觉：删除线/红边小图标，明确语义

### M2 全网多值 AND 检索
- 全网请求：多条件 → 尝试 asmr.one 组合（kikoeru /api/search 支持组合串；对不支持组合的部署降级为串行取并再交集合过滤）
- 标签/CV/社团用 id 精确 + 服务端 AND；无法 AND 时本地对候选并集过滤
- RJ 数字输入自动补 `RJ` 前缀并走 RJ 精确

### M3 高级筛选（搜索结果二次过滤）
- 评分 ≥ x（0-5）、年龄（全年龄/R18）、销量区间（本地：元数据 dl_count）
- 与排除/包含条件同屏折叠面板（advanced filters），实时生效

### M4 建议与联动
- 全表标签/CV/社团缓存到内存（进入搜索一次拉取；设置清理缓存入口）
- 建议项显示 count + 「本地已有 N」徽章（用 RJ source_id 关联本地库）
- 历史搜索项（条件组合串化存储，点击恢复整组条件）

### M5 结果页统一
- 结果含排序（发行/评分/销量/评价量）、视图切换、分页加载、本地徽章、条件 chips 一键改
- 在线结果行"加入想听/收藏"快捷（见我的模块 PRD）

## 四、实施计划（搜索）

| # | 任务 | 涉及 | 估时 |
|---|---|---|---|
| 1 | 条件对象模型 + 统一 chips UI（合并两套模式） | search_screen 重构 | 大 |
| 2 | 全网多值 AND（服务端组合串 + 降级过滤） | api_service + online_search | 中 |
| 3 | RJ 自动前缀 + 高级筛选面板（评分/年龄/销量） | search UI + 过滤 util | 中 |
| 4 | 全表缓存 + 建议联动本地徽章 + 历史条件 | provider | 中 |
| 5 | 结果页统一（排序/视图/徽章/条件编辑） | result/列表组件 | 中 |

**验收**：kikoflu 同款"加标签A → 加 CV 乙 → 排除 标签B → 评分≥4 → 出结果"全流程一次完成；本地与全网行为一致。
