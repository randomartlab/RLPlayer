## 一、kikoflu「我的」设计拆解

### 1. 我的 = 可配置 Tab 聚合页（非单一本地库）

kikoflu `MyScreen` 用 `TabController` 动态构建 tab 列表，**每项可显示/隐藏**（my_tabs_display_settings）：

| Tab | 数据 | 说明 |
|---|---|---|
| 在线标记（online marks） | asmr.one favourites/bookmarks | 收藏列表，含筛选与「下载全部」FAB |
| 历史记录 | 播放历史 | 见 HistoryScreen |
| 播放列表 | 服务端播放列表（官方服务器专属） | |
| 已下载 | 本地下载库（LocalDownloadsScreen） | 支持过滤「仅本地/需下载」、批量操作、下载 FAB |
| 字幕库 | 已下载字幕 | SubtitleLibraryScreen |

- 顶层 toolbar 折叠、tab 切换器、FAB 承载下载进度
- 每个 tab 自带 toolbarTop/collapsed 联动（大页面滚动体验）

### 2. 与账号/服务端状态强相关
- 在线标记依赖登录态与官方服务器；未登录引导
- 「想听/在听/听过/评分/加列表」等**服务端状态**（bookmark manager 有 ratingSet/listAdd/favourite）统一在作品级操作

### 3. 本地下载 = 一等公民
- 下载任务流（task stream）徽章 FAB；下载完成自动归入"已下载"
- 下载库可按"需补下载/字幕缺失"等状态过滤（对齐播放可用性）

## 二、本项目现状

我的 = 5 tab：本地库 / 历史 / 播放列表 / 字幕库 / 下载管理（固定，不可配置）。
本地库= 扫描库全集（含未识别 RJ）；播放列表本地实现；状态（想听/在听/听过/评分）只写在详情页本地 work_status。

**差距**：
1. 无「在线收藏/书签」聚合 tab（已能做：asmr.one favourites API 存在）
2. 无「状态聚合」视图（想听/在听/听过/已评 一览，本地状态表已有数据）
3. Tab 不可配置显示；本地库混入"未识别 RJ"，无可切换视角
4. 下载与"已下载库"混一 tab，无完成/进行中分流视角；无下载缺字幕类状态提示
5. 「我的-本地」仍是扫描库而非"我的收藏/状态"定位
6. 作品级状态（想听等）未与在线收藏互通（双向）

## 三、迭代 PRD（我的）

### M1 Tab 可配置 + 新增「状态」视角
- 我的页 Tab 支持显示设置（长按/设置页开关）：本地库 / 状态清单 / 在线收藏 / 历史 / 播放列表 / 字幕库 / 下载管理
- 新增「状态清单」tab：按 想听/在听/听过/已评 分组（来自 work_status 关联作品），支持清除状态；空态引导
- 「本地库」增加视角切换：全部 / 仅已识别 RJ / 仅未识别（待整理）

### M2 在线收藏聚合
- 「在线收藏」tab：登录后拉 asmr.one favourites（分页/筛选/搜索），每项显示本地徽章与下载按钮；游客引导登录
- 与本地"想听"可选双向：作品卡片长按/操作菜单提供「收藏到 asmr.one」「加入想听」
- 离线时可展示缓存收藏元数据

### M3 下载分流与健康提示
- 下载管理 tab：进行中列表（进度/暂停/取消）+ 已完成列表（打开/删除/重新下载）
- 已完成行显示"缺本地文件/缺歌词/缺字幕"状态徽章（metadata 判断）
- 完成通知、网络类型限制沿用现有偏好

### M4 作品状态与账号互通（详情页强化）
- 详情操作区统一「收藏 / 想听 / 在听 / 听过 / 评分」五项；收藏走 asmr.one（需登录），其余本地
- 「我的-状态清单」里点击作品直接跳详情，评分后立即反馈平均值提示

## 四、实施计划（我的）

| # | 任务 | 涉及 | 估时 |

| 1 | Tab 显示设置 + 状态清单 tab（分组/空态/清除） | my_screen + work_status 查询 | 中 |

## 五、依赖与风险

- 在线收藏需登录 token（多镜像会话已支持）；游客降级提示
- 服务端播放列表不在 kikoeru 通用范围 → 本地播放列表保留为主
- 状态聚合依赖 work_status 已随扫描 replaceAll 保留？——当前 work_status 以 rj_code 为主键、独立于 works 重建，安全；但未识别 RJ 无关联。补 RJ 后应迁移状态行 rj 键
